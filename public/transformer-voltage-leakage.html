变压器 / 电压变换

电压方程：从漏磁通到漏抗

主磁通联系两侧；漏磁通在各自绕组中表现为串联漏抗。

同一台变压器，三部分磁通

悬停漏磁通或漏抗看对应；点击锁定，再次点击解除。曲线示意交链范围。

一次侧（原边）

电流从输入端流入

E1 = −j4.44N1fΦm

U1 = −E1 + (R1 + jX1)I1 = −E1 + Z1I1

输入端电压 = 平衡主磁通电动势 + 绕组阻抗压降

二次侧（副边）

电流流出绕组，送往负载

E2 = −j4.44N2fΦm

U2 = E2 − (R2 + jX2)I2 = E2 − Z2I2

负载关系：U2 = ZLI2（本图 ZL = RL）　｜　Z1,2 = R1,2 + jX1,2

忽略绕组阻抗压降

U1 ≈ −E1　 U2 ≈ E2　⇒　U1 / U2 ≈ N1 / N2

正弦稳态；点号为相量，U、I、E 为有效值，Φm 为主磁通峰值。
线性漏磁模型：Lσ = Ψσ / i，Ψσ 为漏磁链；ω = 2πf。R 为铜阻，X 为漏抗。
