例题 6 · 并励直流发电机电输出与电磁转矩

先求输出与支路电流，再沿功率流反推电磁功率与转矩。

题目 · 例 7.10.1SHUNT DC GENERATOR

一并励直流发电机，已知：

输出电压
U = 230 V
输出电流
I = 100 A
电枢电阻
Ra = 0.2 Ω
励磁电阻
Rf = 115 Ω
转速
n = 1500 r/min
空载转矩
T0 = 17.32 N·m
求
  1. 输出功率 P2、电磁转矩 T；
  2. 输入功率 P1、效率 η（下一页）。
计算过程与答案电输出 → 铜耗 → 电磁转换
  1. 01

    输出端：电功率由输出电流计算

    P2 = UI = 230 × 100 = 23 000 W

  2. 02

    并励支路：电枢电流为两支路电流之和

    If = U / Rf = 230 / 115 = 2 A

    Ia = I + If = 100 + 2 = 102 A

  3. 03

    铜耗：分别使用电枢电流与励磁电流

    PCu = RaIa² + RfIf²

    = 0.2 × 102² + 115 × 2² = 2540.8 W

  4. 04

    电磁功率：电输出加铜耗

    Pe = P2 + PCu = 23 000 + 2540.8

    = 25 540.8 W

  5. 05

    电磁转矩：电磁功率除以角速度

    Ω = 2πn / 60 ≈ 6.28 × 1500 / 60 = 157 rad/s

    T = Pe / Ω = 25 540.8 / 157 ≈ 162.68 N·m

按题图取 2π ≈ 6.28，忽略电刷压降。T 为电磁制动转矩的大小，方向与转速相反；Pe 即前页的 Pem。
