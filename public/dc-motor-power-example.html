例题 4 · 并励直流电动机功率与效率计算

先根据题意独立列式，再点击按钮核对计算过程。

题目 · 例 7.8.1SHUNT DC MOTOR

一并励电动机，已知参数如下：

额定电压
UN = 110 V
额定输入电流
IN = 12.5 A
额定转速
nN = 1500 r/min
负载转矩
TL = 6.8 N·m
空载转矩
T0 = 0.9 N·m
求
  1. 输出功率 P2 与电磁功率 Pe；
  2. 输入功率 P1 与总损耗 Pal；
  3. 电动机效率 η。
计算过程与答案由转矩求功率，再求效率
  1. 01

    由负载转矩求轴端输出功率

    P2 = (2π / 60)TLnN ≈ (6.28 / 60) × 6.8 × 1500 = 1067.6 W

  2. 02

    由空载转矩求空载损耗功率

    P0 = (2π / 60)T0nN ≈ (6.28 / 60) × 0.9 × 1500 = 141.3 W

  3. 03

    由机械功率平衡求电磁功率

    Pe = P2 + P0 = 1067.6 + 141.3 = 1208.9 W

  4. 04

    由额定电压、电流求输入功率

    P1 = UNIN = 110 × 12.5 = 1375 W

  5. 05

    由整机功率平衡求总损耗

    Pal = P1 − P2 = 1375 − 1067.6 = 307.4 W

  6. 06

    由输出与输入功率之比求效率

    η = (P2 / P1) × 100% = (1067.6 / 1375) × 100% ≈ 77.64%

按题图取 2π ≈ 6.28，稳态转速 n = nN。 P0 为 141.3 W（题图 143.3 W 为笔误）；Pe 即前页的 Pem。
