例 2.5.1 · 用两种等效电路求负载电流与电压

题目 · 例 2.5.1SINGLE-PHASE TRANSFORMER

单相变压器在额定一次电压下带载运行。

两侧额定电压
U1N/U2N = 380/190 V
一次侧施加电压
U̇₁ = 380∠0° V
一次绕组阻抗
Z₁ = (0.4 + j0.8) Ω
二次绕组阻抗
Z₂ = (0.15 + j0.3) Ω
励磁阻抗
Z₀ = (600 + j1200) Ω
负载阻抗
ZL = (7.5 + j4.75) Ω
求
  1. 用 T 形等效电路求负载电流和电压的有效值；
  2. 用简化等效电路求上述两个有效值。
计算过程与答案T 形与简化等效电路
  1. 01

    把二次绕组阻抗和负载阻抗折算到一次侧

    k = 380/190 = 2，Z₂′ = k²Z₂ = (0.6 + j1.2) Ω

    ZL′ = k²ZL = (30 + j19) Ω

  2. 02

    用 T 形等效电路计算

    Z = Z₁ + [Z₀ ∥ (Z₂′ + ZL′)] ≈ 36.60∠34.88° Ω

    İ₁ = U̇₁ / Z ≈ 10.38∠(−34.88°) A

    Ė₂′ = Ė₁ = Z₁İ₁ − U̇₁ ≈ 371.87∠179.32° V

    İ₂′ = Ė₂′ / (Z₂′ + ZL′) ≈ 10.14∠145.89° A

    I₂ = k|İ₂′| ≈ 20.28 A， U₂ = |ZL| I₂ ≈ 180.08 V

  3. 03

    忽略励磁支路，用简化等效电路计算

    Zs = Z₁ + Z₂′ = (1.0 + j2.0) Ω

    Zs + ZL′ = (31 + j21) Ω

    İ₁ = −İ₂′ = U̇₁ / (Zs + ZL′) ≈ 10.15∠(−34.11°) A

    I₂ = k|İ₂′| ≈ 20.30 A， U₂ = |ZL| I₂ ≈ 180.19 V

∥ 表示阻抗并联。用未舍入的中间值计算，两种模型的负载电压相差约 0.12 V。
