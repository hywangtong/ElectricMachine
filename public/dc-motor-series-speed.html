串励电动机：转速与软机械特性

由 U = E + (Ra + Rf)I、I = Ia = If，以及 E = CEΦn、T = CTΦIa 联立得到：

n = ECEΦ = U − (Ra + Rf)IaCEΦ

n = UCEΦ − Ra + RfCECTΦ2T

04 软机械特性

串励电动机的机械特性
转速随负载变化明显 · 定性示意

① 理想空载 · T = 0

Ia = If = 0，Φ = Φr，只剩微小剩磁。

n0 很大；课件给出 n0 = (5～6)nN。

② T 很小 · Ia 很小 · 磁路未饱和

T ↑ → Ia ↑ → Φ ↑ → n 迅速下降

在此区间，转速近似与负载电流成反比：n ∝ 1/Ia。

③ T 很大 · Ia 很大 · 磁路已饱和

T ↑ → Ia ↑ → Φ 基本不变 → n 下降较少

类似他励电动机，转速随负载增大而略有下降。

资料：用户附件第 3 页。Φ 随 Ia 变化；(5～6)nN 为课件示例量级。实际空载仍有损耗转矩及小电流，不能按此倍数判断允许运行转速。
