直流发电机：功率与转矩公式汇总

从轴端机械输入到负载电输出，用功率平衡求原动机必须提供的转矩。

01 输出功率与铜耗推导

P2 = Pe − PCu = UI

推导

EIa = (U + RaIa) Ia

= U(I + If) + RaIa2

= UI + RfIf2 + RaIa2

02 功率转换与输入

机械输入

P1 = T1Ω = 2π60 T1n

空载损耗

P0 = PFe + Pme + Pad

电磁功率

Pe = P1 − P0

= EIa = TeΩ

03 转矩平衡与计算

P1 = P0 + Pe

T1 = T0 + Te

输入转矩

T1 = P1Ω = 602π P1n

电磁转矩

Te = PeΩ = 602π Pen

空载转矩

T0 = P0Ω = 602π P0n

04 稳态运行关系

转矩方向

T1 驱动；Te、T0 阻转

忽略空载转矩时

T1 = Te

Ω = 2πn/60；n：r/min，Ω：rad/s，功率：W，转矩：N·m。转矩公式取大小，Ω > 0。

PDF 中 T 对应本页 Te；沿用 P0 = PFe + Pme + Pad。铜耗推导适用于稳态并励发电机，忽略电刷接触电损耗。
