并励直流发电机的功率与损耗

原动机输入的机械功率，一部分转化为负载电功率，其余消耗在发电机内部。

功率平衡

P1 − P2 = Pal = PFe + PCu + Pme + Pad

效率

η = (P2 / P1) × 100%

并励电路：左侧轴输入，右侧电输出

Ia = I + If · Ua = Uf = U

总损耗 Pal：四部分相加

铜损耗 PCu

PCu = RaIa2 + RfIf2

电枢铜耗 + 励磁铜耗

铁损耗 PFe

电枢铁心中的损耗

磁滞损耗与涡流损耗

机械损耗 Pme

摩擦与通风损耗

轴承、电刷摩擦及风阻等

附加损耗 Pad

杂散负载损耗

负载下磁场畸变等引起的额外损耗

从轴端到负载：功率逐级扣除损耗

输入机械功率

P1 = T1Ω

− PFe − Pme − Pad

⟶ 扣除铁耗、机械与附加损耗

电磁转换功率

Pe = TeΩ = EIa

− RaIa2 − RfIf2

⟶ 扣除电枢与励磁铜耗

输出电功率

P2 = UI

稳态并励发电，忽略电刷接触电损耗；T1 为输入转矩，Te 为电磁制动转矩的大小；Ω = 2πn/60（rad/s），功率单位 W。
