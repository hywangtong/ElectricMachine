磁路 / 07 计算方法 · ELI5

怎样把磁场问题变成磁路计算？

抓住主磁通通道：磁通势推动，磁阻限制；在节点分磁通，沿回路加磁位降。

电路 → 磁路：用类比建立直觉

电压 U→磁通势 F推动
电流 I→磁通 Φ通过
电阻 R→磁阻 Rm限制
I = U/R↔Φ = F/Rm
F = NI磁通势 · A·turn
Rm = l/(μA)磁阻 · A·turn/Wb
l ↑ → Rm ↑A ↑ → Rm ↓μ ↑ → Rm ↓
Φ = NI/Rm简单单支路磁路

基尔霍夫定律：先分磁通，再列回路

01 节点 · 磁通连续

Φ = Φ₁ + Φ₂

流入的磁通 = 流出的磁通

代数和：ΣΦ = 0

02 回路 · 磁位降求和

Uₘ₁ + Uₘ₂ + Uₘ₃ = F

每段磁位降：Uₘᵢ = Hᵢlᵢ

一般形式：ΣUₘ = ΣF

标准计算链 铁心非线性时，由 B-H 曲线查 H；常数 μ 只用于明确的线性近似。

  1. ① 确定磁通Φ / Φᵢ
  2. ② 求磁通密度Bᵢ = Φᵢ/Aᵢ
  3. ③ 查 B-H 曲线得到 Hᵢ
  4. ④ 求各段磁位降Uₘᵢ = Hᵢlᵢ
  5. ⑤ 得到所需安匝数NI = ΣHᵢlᵢ
工程结论磁通势推动磁通，磁阻限制磁通；复杂磁路靠“磁通连续 + 磁位降求和”组织计算。
