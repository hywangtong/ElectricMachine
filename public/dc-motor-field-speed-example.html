例 8.3.3 · 恒功率负载弱磁调速

先由恒功率条件确定转矩，再求磁通，并用理想空载转速限制选根。

题目 · 例 8.3.3FIELD WEAKENING

例 8.3.1 中的他励电动机，拖动恒功率负载运行，现采用改变励磁电流调速。

电枢电压
Ua = 160 V
电枢电阻
Ra = 1.27 Ω
额定转速
nN = 1450 r/min
额定转矩
TN = 26.36 N·m
求

要使转速增加至 1800 r/min，并希望理想空载转速 n0 不超过 3000 r/min，CEΦ 应等于多少？

电枢电压保持不变，不外串电阻；忽略空载转矩 T0，按 T ≈ TL 计算。

  1. 01

    恒功率负载：T ∝ 1/n，先求目标转速下的转矩

    T=nNnTN=14501800×26.36≈21.23 N·m
  2. 02

    代入机械特性方程

    n=UaCEΦ−RaCECTΦ2T

    n 用 r/min，CT = 9.55 CE。令 x = CEΦ，得

    1800=160x−1.27×21.239.55x2
  3. 03

    两边乘 x²，整理成一元二次方程

    1800 x² − 160 x + 2.82 ≈ 0

    其中 1.27 × 21.23 / 9.55 ≈ 2.82。

恒功率满足 Tn = TNnN；升速后负载转矩减小，不能直接沿用额定转矩。各步沿用题图舍入值。

  1. 04

    解二次方程，得到两个候选值

    x=160±1602−4×1800×2.822×1800

    CEΦ ≈ 0.0647 或 0.0242

  2. 05

    分别校核理想空载转速 n₀ = Uₐ / (CEΦ)

    取 0.0647：n₀ ≈ 160 / 0.0647 ≈ 2473 r/min

    2473 < 3000，满足限制。

    取 0.0242：n₀ ≈ 160 / 0.0242 ≈ 6612 r/min

    6612 > 3000，不满足限制，舍去。

  3. 答

    应选择的电动势系数与磁通之积

    CEΦ ≈ 0.0647 V/(r/min)

两个代数根都需用题设约束筛选；这里限制的是理想空载转速 n₀，而目标负载转速为 n = 1800 r/min。
