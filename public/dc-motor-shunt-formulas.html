并励直流电动机的基本公式

励磁绕组与电枢并联在同一电源两端：端电压相同，输入电流分成两路。

01 输入电压

U = Ua = Uf

电枢与励磁绕组共用端电压 U

02 输入电流

I = Ia + If

电源电流 = 电枢电流 + 励磁电流

03 输入功率

P1 = UI = UIa + UIf

电源同时向电枢和励磁绕组供电

同一电源 · 两条并联支路

列式顺序：先由 U 求 If，再从输入电流 I 中扣除 If，得到 Ia。

励磁支路

If = U / Rf

电枢支路

E = U − RaIa

机电转换关系

E = CEΦn

T = CTΦIa

稳态电动运行，忽略电刷接触压降；U 用 V，I 用 A，R 用 Ω，n 用 r/min，T 为电磁转矩（N·m）。
