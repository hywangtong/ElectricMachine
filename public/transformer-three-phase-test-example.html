例 2.6.1 · 三相变压器的空载与短路试验计算

题目 · 例 2.6.1THREE-PHASE TRANSFORMER

一台 Y,d 联结的三相变压器，铜绕组，室温 20 °C。

额定容量
SN = 750 kV·A
额定线电压（高压 / 低压）
U1N/U2N = 10 000/231 V
额定线电流（高压 / 低压）
I1N/I2N = 43.3/1 874 A
试验 线电压 / V 线电流 / A 三相功率 / W 加压侧
空载 231/10 000 103.8 3 800 低压侧
短路 440 43.3 10 900 高压侧
求
  1. 折算到高压侧的每相空载参数 |Z₀|、R₀、X₀。
  2. 高压侧每相短路参数 |Zs|、Rs、Xs（折算至 75 °C）。
计算过程与答案每相等效参数
  1. 01

    空载试验：在低压侧（d 接）求每相参数

    Uφ = 231 V，Iφ = 103.8 / √3 A，Pφ = 3 800 / 3 W

    |Z₀| = Uφ / Iφ ≈ 3.85 Ω，R₀ = Pφ / Iφ² ≈ 0.35 Ω

    X₀ = √(|Z₀|² − R₀²) ≈ 3.84 Ω

  2. 02

    用相电压比的平方将空载参数折算到高压侧

    k = (10 000 / √3) / 231 ≈ 24.99

    k²(|Z₀|, R₀, X₀) ≈ (2 408, 220, 2 398) Ω

  3. 03

    短路试验：在高压侧（Y 接）求每相参数

    Uφ = 440 / √3 V，Iφ = 43.3 A，Pφ = 10 900 / 3 W

    |Zs| = Uφ / Iφ ≈ 5.87 Ω，Rs = Pφ / Iφ² ≈ 1.94 Ω

    Xs = √(|Zs|² − Rs²) ≈ 5.54 Ω

  4. 04

    折算到 75 °C：修正铜绕组电阻，漏抗取原值

    Rs,75 = [(234.5 + 75) / (234.5 + 20)] Rs,20 ≈ 2.36 Ω

    Xs,75 ≈ 5.54 Ω，|Zs,75| = √(Rs,75² + Xs,75²) ≈ 6.02 Ω

表中空载线电压按低压侧 / 高压侧列出。计算过程保留未舍入的中间值。
