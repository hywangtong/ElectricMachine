并励直流电动机的功率与损耗

电源输入的电功率，一部分转化为轴端机械功率，其余消耗在电机内部。

功率平衡

P1 − P2 = Pal = PFe + PCu + Pme + Pad

效率

η = (P2 / P1) × 100%

电枢与励磁绕组并联

I = Ia + If · Ua = Uf = U

总损耗 Pal：四部分相加

铜损耗 PCu

PCu = RaIa2 + RfIf2

电枢铜耗 + 励磁铜耗

铁损耗 PFe

电枢铁心中的损耗

磁滞损耗与涡流损耗

机械损耗 Pme

摩擦与通风损耗

轴承、电刷摩擦及风阻等

附加损耗 Pad

杂散负载损耗

负载下磁场畸变等引起的额外损耗

从电源到轴端：功率逐级扣除损耗

输入电功率

P1 = UI

− RfIf2 − RaIa2

⟶ 扣除励磁与电枢铜耗

电磁转换功率

Pem = EIa = TeΩ

− PFe − Pme − Pad

⟶ 扣除铁耗、机械与附加损耗

轴端输出功率

P2 = T2Ω

稳态电动运行，忽略电刷接触损耗；Te 为电磁转矩，T2 为轴端输出转矩；Ω = 2πn/60（rad/s），功率单位 W。
