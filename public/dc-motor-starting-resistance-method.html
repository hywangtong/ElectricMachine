直流拖动 / 8.2 · 分级启动电阻的计算 · 01

先定电流范围，再求每一段启动电阻

他励电动机 · Uₐ = UaN、Φ = ΦN 恒定 · 恒转矩负载 · 已知 UaN、Rₐ、IaN、IL

计算流程 箭头表示计算顺序

1选择启动电流 I₁ 与切换电流 I₂

I₁ = (1.5～2.0) IaN；I₂ = (1.1～1.2) IL

恒磁通下 T ∝ Iₐ；还须满足 IL < I₂ < I₁ < IM。

2初算电流比与最大总电阻

β₀ = I₁ / I₂；Ram = UaN / I₁

3确定启动级数 m（正整数）

m* = lg(Ram / Rₐ) / lg β₀

先取 m = ⌈m*⌉；若校验失败，调整 m 或重选电流。

4按整数级数修正 β，重新求 I₂

β = (Ram / Rₐ)1/m；I₂ = I₁ / β

保持选定的 I₁ 与 Ram 不变，不能沿用初选 β₀。

I₂ 是否在规定范围内？且 IL < I₂ < I₁ < IM

5求各段外接电阻，校核总和

RSTi = (βi − βi−1) Rₐ，i = 1,…,m

ΣRSTi = Ram − Rₐ；启动时按 m → 1 切除。

调整 m
或返回①
重选电流

机械特性：等转速切阻

示例参数见下一页。斜线：加速；水平箭头：等转速切阻。

公式从哪里来？

切除第 i 段前后，转速相同，因此反电动势相同：

UaN − RaiI₂ = UaN − Ra,i−1I₁
Rai = βRa,i−1 = βiRₐ

令 Ra0 = Rₐ；全部 m 段串入时 Ram = βmRₐ。

总电阻 Rai ≠ 分段电阻 RSTiRai 含 Rₐ；RSTi = Rai − Ra,i−1。
m：外接电阻段数，也是切除次数；IL：负载转矩对应的电枢电流；IM：允许短时过载电流。忽略电感、电刷压降与电枢反应；切换电流表示准稳态值，真实电感电流连续。
