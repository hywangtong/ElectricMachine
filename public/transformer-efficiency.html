变压器：效率公式的推导

单相变压器稳态运行：从有功功率平衡出发，用空载与短路试验数据估算效率。

01 写出功率平衡

功率取有功值，损耗只计铁耗与铜耗。

P1 = P2 + PFe + PCu η = (P2 / P1) × 100%

02 用负载系数表示输出

一次侧按额定电压和频率供电。电压调整率 VR 很小时，取 U2 ≈ U2N。

P2 = U2I2 cos φ2 ≈ U2NI2N (I2 / I2N) cos φ2 = βSNλ2

β = I2 / I2N 为负载系数， SN = U2NI2N 为额定容量， λ2 = cos φ2 为负载功率因数。

结果一 · 保留铁耗与铜耗

η≈ βSNλ2 βSNλ2 +PFe +PCu ×100%

03 用试验功率代入损耗

PFe ≈ P0

电压、频率不变时，铁耗近似恒定；空载铜耗很小，取额定电压下的空载试验功率 P0。

PCu ≈ (I1 / I1N)2Ps ≈ β2Ps

同一绕组温度下，铜耗随电流平方变化。短路试验电压低、铁耗很小，取额定电流下测得的 Ps 作为额定铜耗。空载电流相对负载电流很小时， I1 / I1N ≈ β。

结果二 · 用空载与短路试验数据计算

η≈ βSNλ2 βSNλ2 +P0 +β2Ps ×100%

最大效率点：PFe = PCu 功率因数固定时，效率最高对应 P0/β + βPs 最小，即两项相等：P0 = β²Ps。

若电压调整率不可忽略，输出应按实际端电压 U2 计算。
