直流电动机：功率与转矩公式汇总

从输入电功率到轴端输出功率，从电磁转矩到负载转矩。

01 电磁功率与输入功率推导

Pe = P1 − PCu = EIa

推导

UI = U(Ia + If) = UIa + UIf

= (E + RaIa) Ia + RfIf2

= EIa + RaIa2 + RfIf2

02 功率转换与输出

电磁功率

Pe = EIa = CEΦnIa

= 2π60 CTΦnIa = TeΩ

空载损耗

P0 = PFe + Pme + Pad

输出功率

P2 = Pe − P0 = T2Ω

= 2π60 T2n

03 转矩平衡与计算

P2 = Pe − P0 = T2Ω

T2 = Te − T0

输出转矩

T2 = P2Ω = 602π P2n

电磁转矩

Te = PeΩ = 602π Pen

空载转矩

T0 = P0Ω = 602π P0n

04 稳态运行关系

在稳定运行时

T2 = TL

忽略空载转矩时

Te = T2 = TL

Ω = 2πn/60；n：r/min，Ω：rad/s，功率：W，转矩：N·m。TL 为负载转矩。

Pe 即前页 Pem，Te 为电磁转矩；输入功率推导适用于并励电动机，忽略电刷接触损耗。
