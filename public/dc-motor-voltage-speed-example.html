例 8.3.2 · 改变电枢电压调速

恒转矩、恒磁通：由转速降落求理想空载转速，再求电枢电压。

题目 · 例 8.3.2ARMATURE VOLTAGE CONTROL

例 8.3.1 中的他励电动机，拖动恒转矩负载运行， TL = TN。

电枢电阻
Ra = 1.27 Ω
电动势系数与磁通之积
CEΦ = 0.0802
转矩系数与磁通之积
CTΦ = 0.766
额定转矩
TN = 26.36 N·m
求

现采用改变电枢电压调速。试问要使转速降低至 1000 r/min，电枢电压应降低到多少？

计算过程与答案Δn → n₀ → Uₐ
  1. 01

    恒转矩负载：电磁转矩取额定转矩，求转速降落

    Δn = Ra CECTΦ² T = 1.270.0802 × 0.766 × 26.36

    ≈ 544.94 r/min

  2. 02

    由目标转速求该电压下的理想空载转速

    n0 = n + Δn

    ≈ 1000 + 544.94 = 1544.94 r/min

  3. 03

    磁通保持不变，求所需电枢电压

    Ua = CEΦ n0

    ≈ 0.0802 × 1544.94 = 123.9 V

按题图取 T = TL = TN，忽略空载转矩与电刷压降；励磁不变，电枢不外串电阻。 恒转矩时 Δn 不变，降低 Ua 使机械特性平行下移。
