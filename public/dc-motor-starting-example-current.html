例 8.2.1 · 电枢串电阻起动计算

从允许的起动电流范围出发，求起动级数和各级起动电阻。

题目 · 例 8.2.1SEPARATELY EXCITED DC MOTOR

一台 Z₄ 系列他励直流电动机

额定功率
PN = 200 kW
额定电枢电压
UaN = 440 V
额定电枢电流
IaN = 497 A
额定转速
nN = 1500 r/min
电枢电阻
Ra = 0.076 Ω
求
  1. 采用电枢串电阻起动，求起动级数 m。
  2. 求各级总电阻及各段起动电阻。
  1. 01

    选择起动电流上限 I₁

    I₁ = (1.5～2.0) IaN

    = (745.5～994) A，取 I₁ = 840 A

  2. 02

    选择切换电流 I₂

    I₂ = (1.1～1.2) IaN

    = (546.7～596.4) A，取 I₂ = 560 A

  3. β

    求起动电流比（初选值）

    β = I₁ / I₂ = 840 / 560 = 1.5

    取整数级数后，需要重新计算 β 和 I₂。

I₁ 为每级起动的电流上限，I₂ 为切除下一段电阻前的电流；本例电流范围按题图选取。

  1. 03

    求最大电枢回路总电阻（含 Ra）

    Ram = UaN / I₁ = 440 / 840 ≈ 0.524 Ω

  2. m

    由 Ram = βmRa 求级数

    m* = lg(Ram / Ra) / lg β

    = lg(0.524 / 0.076) / lg 1.5 ≈ 4.76，取 m = 5 级

  3. 04

    固定 I₁ 和最大总电阻，重新计算 β

    β = (Ram / Ra)1/m

    = (0.524 / 0.076)1/5 ≈ 1.47

  4. I₂

    修正切换电流并校验范围

    I₂ = I₁ / β = 840 / 1.47 ≈ 571 A

    546.7 A ≤ 571 A ≤ 596.4 A，五级方案可用。

取整数级数后应修正电流比，不能沿用初选 β = 1.5。

⑤ 各级总电阻与各段外接电阻

Rai = βiRa；Ra0 = Ra = 0.076 Ω

RSTi = Rai − Ra,i−1 = (βi − βi−1) Ra

编号从固有机械特性向外递增；电阻单位均为 Ω。
段号 各级总电阻 Rai 各段外接电阻的计算 RSTi
1 1.47 × 0.076 ≈ 0.1117 (1.47 − 1) × 0.076 0.0357
2 1.47² × 0.076 ≈ 0.1642 (1.47² − 1.47) × 0.076 0.0525
3 1.47³ × 0.076 ≈ 0.2414 (1.47³ − 1.47²) × 0.076 0.0772
4 1.47⁴ × 0.076 ≈ 0.3549 (1.47⁴ − 1.47³) × 0.076 0.1135
5 1.47⁵ × 0.076 ≈ 0.5217 (1.47⁵ − 1.47⁴) × 0.076 0.1668
切除顺序：RST5 → RST4 → RST3 → RST2 → RST1

全部切除后，仅剩电枢电阻 Ra。

按题图取 β = 1.47，各段之和约 0.4457 Ω，加 Ra 后约 0.5217 Ω；与 0.524 Ω 的小差异来自 β 的舍入。保留未舍入 β≈1.47120 时，总电阻为 440 / 840≈0.52381 Ω。
