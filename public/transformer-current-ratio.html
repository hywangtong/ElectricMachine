变压器 / 从电压变换到电流变换

电流变换比

同一个结论，两条推导路径：电压升高，电流减小；电压降低，电流增大。

01 从功率平衡看

理想变压器：忽略损耗与励磁电流，两侧功率因数相同。

P1 = P2

U1I1cos φ1 = U2I2cos φ2

理想模型有功、无功均守恒，故两侧视在功率相等：

U1I1 = U2I2

I1I2 = U2U1 = 1k

传递相同功率，电压比与电流比互为倒数。

02 从电磁关系看

电源电压、频率不变时： Φm ≈ U1N/(4.44N1f) ≈ 常数

磁路基尔霍夫定律：
两侧磁动势之和维持主磁通

F1 + F2 = F0

N1I1 + N2I2 = N1I0

原边新增磁动势补偿副边去磁作用；合成的 F0 与空载时近似相同。

I0 为空载电流 满载或接近满载时，I0 ≪ I1，可忽略。 满载：I2 = I2N，I1 ≈ I1N

N1I1 + N2I2 ≈ 0 ⇒ I1 ≈ −N2N1I2

电流变换 · 大小关系

满载近似；理想变压器取等号

I1I2 ≈ N2N1 = 1k

回顾电压比
k = N1/N2 ≈ U1/U2
