## 阅读与维护约定

本文中的“页”包括课程翻页页面、具有独立地址的页内标签内容、独立 HTML 专题，以及目录等公共界面状态。网站主入口只有 `/`；课程页通过 `/#页面ID` 定位，不是多个独立路由。

当前课程数据有 37 个内容记录，播放器有 30 个翻页位置。新能源汽车的 8 个记录共用第 7 个翻页位置，其余 7 个标签不增加总页码。本文按实际翻页顺序记录，并将这 8 个标签逐一展开。绪论占 17 个翻页位置，其余六章各占 2 个。

每页使用下列状态约定：

- 标签“已完成”：当前页面的所述内容和交互已在源码实现；不表示整章教学已经讲完，也不代表外部服务已经验证可用。
- 标签“未完成”：页面明确属于提纲，或尚缺少实现其教学目标所需的详细内容。
- 每页分别记录“已完成内容”和“未完成内容”。已实现页没有明确待办时写“无明确待办”；提议的新内容必须写在未完成项中，不能当成网站现有文案。

“全部内容”包括现有标题、正文、表格、按钮、图示含义、条件显示内容、交互反馈和资料链接；装饰性 SVG 坐标、CSS 类名及脚手架中未使用的组件不属于教学内容。嵌入的外部视频只记录网站现有说明、播放器和入口，没有逐字稿，不推测视频内部内容。资料中的查阅日期和事实边界按源码记录，本文不构成重新查证结果。

为了保持低格式，本文只用标题、普通段落和单层列表，不依赖截图、复杂表格、HTML 或样式。重复出现的公共内容集中记录一次，每页默认继承；独立吊舱版的八页复用同 ID 的正文说明。

维护时先定位稳定 ID，再同时更新本文和对应课程数据、组件或 HTML。新增页先按文末模板写“未完成”描述，明确内容、关系与验收条件，实际实现后再改状态。页面 ID 保持唯一、稳定、kebab-case；章节归属必须存在。修改顺序时同时核对翻页顺序、前后页关系和页内标签的特殊导航规则。

### 07.6 氢燃料电池汽车

### 15 绪论：好用，也要过三道关

已完成内容：标题“好用，也要过三道关”；副题“大船选推进系统，要把整条能量链一起看”。三张挑战卡：

- ≈ 水下关：海水会腐蚀，轴在转，舱体必须密封；轴承、冷却都要可靠。少了长轴系和齿轮环节，水下设备仍需维护。

- ↗ 匹配关：船型、速度、桨和航线要一起设计；水流、空化和阻力都影响效率。节能看船型与运行工况，不能给所有船同一个百分比。

三张类比卡：

- 🍲 综合＝一起分饭：从“推进一口锅、设备一口锅”，变成共享电源。谁需要多少，按任务协调。

- ➡️ 直流＝不用对拍子：发电侧先整流，主干不要求各发电机交流频率同步。末端仍可变成交流。

折叠区“再往里看一层：为何难？”包含全部两段：

- 共享也会相互影响。大负载突然启动，可能拉低电压；短路时，直流电流没有交流那样自然的过零机会。要让保护、变换器、储能和控制协同工作。
- 全电推进描述能量怎样到螺旋桨，不代表只用电池，也不代表一定用核动力。综合电力系统可以采用交流主干，也可以采用直流主干。

- 规则 1“电荷周围有电场”——电场的高斯定律。附公式 $\oiint_S \mathbf{E}\cdot d\mathbf{A}=Q_{\text{内}}/\varepsilon_0$；Q 内为封闭面内部的净电荷，ε₀ 为真空介电常数。大图画正电荷的箭头向外、负电荷的箭头向内；用“看不见的指路箭头”解释电场线。教师说明：完整定律把封闭面上的净电通量与内部净电荷联系起来，电场还可以由变化的磁场产生。
- 规则 2“磁场没有单独的起点或终点”——磁场的高斯定律。附公式 $\oiint_S \mathbf{B}\cdot d\mathbf{A}=0$；B 为磁感应强度，S 为封闭面，面积方向取向外。大图画条形磁铁外部 N → S、内部 S → N 的完整回路；短句“剪开磁铁，得到的还是各有 N、S 两极的小磁铁”。教师说明：穿入与穿出封闭面的磁通相抵；条形磁铁的闭合线是本图示例，不将所有空间中的磁力线都说成有限闭合圆圈。
- 规则 3“磁场在变，电场会绕起来”——法拉第电磁感应定律。附公式 $\oint_C \mathbf{E}\cdot d\mathbf{l}=-d\Phi_B/dt$；Φ_B 为回路所围曲面的磁通，负号体现楞次定律。大图对比“磁铁相对线圈移动”和“磁铁、线圈相对静止且磁场不变”；短句“穿过线圈的磁通变化，线圈就有感应电动势”。注明“闭合回路才可能有持续感应电流”，用静止对比避免误解为只要有磁铁就发电；感应方向遵循楞次定律，后续再展开。
- 规则 4“电流和变化的电场，都与环绕的磁场有关”——安培—麦克斯韦定律。附公式 $\oint_C \mathbf{B}\cdot d\mathbf{l}=\mu_0 I+\mu_0\varepsilon_0 d\Phi_E/dt$；I 为穿过回路所围曲面的导电电流，μ₀ 为真空磁导率，Φ_E 为电通量，第二项对应变化电场的贡献。主图画通电导线及环绕磁场，短句“导线通电，周围出现磁场”；小图画充电电容器的极板间电场正在变化，注明“间隙没有导电电流，变化电场仍贡献磁场”。用这张小图认识麦克斯韦补充项，不把位移电流画成电荷穿过绝缘间隙。
