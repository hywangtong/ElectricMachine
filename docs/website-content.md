## 阅读与维护约定

本文中的“页”包括课程翻页页面、具有独立地址的页内标签内容、独立 HTML 专题，以及目录等公共界面状态。网站主入口只有 `/`；课程页通过 `/#页面ID` 定位，不是多个独立路由。

当前课程数据有 37 个内容记录，播放器有 30 个翻页位置。新能源汽车的 8 个记录共用第 7 个翻页位置，其余 7 个标签不增加总页码。本文按实际翻页顺序记录，并将这 8 个标签逐一展开。绪论占 17 个翻页位置，其余六章各占 2 个。

每页使用下列状态约定：

- 标签“已完成”：当前页面的所述内容和交互已在源码实现；不表示整章教学已经讲完，也不代表外部服务已经验证可用。
- 标签“未完成”：页面明确属于提纲，或尚缺少实现其教学目标所需的详细内容。
- 每页分别记录“已完成内容”和“未完成内容”。已实现页没有明确待办时写“无明确待办”；提议的新内容必须写在未完成项中，不能当成网站现有文案。

“全部内容”包括现有标题、正文、表格、按钮、图示含义、条件显示内容、交互反馈和资料链接；装饰性 SVG 坐标、CSS 类名及脚手架中未使用的组件不属于教学内容。嵌入的外部视频只记录网站现有说明、播放器和入口，没有逐字稿，不推测视频内部内容。资料中的查阅日期和事实边界按源码记录，本文不构成重新查证结果。

为了保持低格式，本文只用标题、普通段落和单层列表，不依赖截图、复杂表格、HTML 或样式。重复出现的公共内容集中记录一次，每页默认继承；独立吊舱版的八页复用同 ID 的正文说明。

维护时先定位稳定 ID，再同时更新本文和对应课程数据、组件或 HTML。新增页先按文末模板写“未完成”描述，明确内容、关系与验收条件，实际实现后再改状态。页面 ID 保持唯一、稳定、kebab-case；章节归属必须存在。修改顺序时同时核对翻页顺序、前后页关系和页内标签的特殊导航规则。

### 07.6 氢燃料电池汽车

### 15 绪论：好用，也要过三道关

页面 ID：ship-pod-tradeoffs。地址：`/#ship-pod-tradeoffs`。类型：pod / tradeoffs。主位置：15 / 30。标签：已完成。

已完成内容：标题“好用，也要过三道关”；副题“大船选推进系统，要把整条能量链一起看”。三张挑战卡：

- ≈ 水下关：海水会腐蚀，轴在转，舱体必须密封；轴承、冷却都要可靠。少了长轴系和齿轮环节，水下设备仍需维护。

- ↗ 匹配关：船型、速度、桨和航线要一起设计；水流、空化和阻力都影响效率。节能看船型与运行工况，不能给所有船同一个百分比。

## 未完成内容与新网页规划

当前明确未完成的是七章提纲所对应的详细教学内容，而不是导航外壳。绪论已经有应用导入；磁路、直流电机理论、直流拖动、变压器、异步电机理论、异步拖动目前只有导入和提纲。以下是据现有目标提出的规划方法，未被实现，也不是新增的现有课程页面：

- 标签：未完成。绪论详细页围绕电机分类、机电能量转换、电力拖动系统组成展开，用现有汽车、飞机和船舶案例作回顾。验收：能把具体应用对应到电源、电机、传动与负载，并说明能量流向。
- 标签：未完成。磁路按基本量 → 定律与计算 → 材料非线性 → 交流损耗拆页。验收：每个量有符号、单位和物理意义，例题有条件、步骤与结果，图解与公式对应。
- 标签：未完成。直流电机按结构 → 工作原理 → 励磁和电枢反应 → 方程与功率 → 发电及电动特性拆页。验收：学生能从结构解释换向，并用方程说明转矩、电动势和运行变化。
- 标签：未完成。直流拖动按动力学 → 运行点与稳定性 → 起动 → 各类制动 → 各类调速及过渡过程拆页。验收：电路、曲线和能量流相互对应，能比较适用条件。
- 标签：未完成。变压器按结构与感应 → 空载 → 负载 → 等效电路与折算 → 两类试验 → 效率 → 三相联结及并联拆页。验收：从试验得到参数，再用模型分析负载性能。
- 标签：未完成。异步电机按三相旋转场 → 转差和感应 → 等效模型 → 功率流 → 转矩和额定性能拆页。验收：图解、转差关系、模型和曲线形成连贯解释。
- 标签：未完成。异步拖动按机械特性 → 起动方法 → 制动方式 → 三种调速原理与比较拆页。验收：能说明参数变化如何影响特性，并与直流拖动形成比较。

新页描述模板（规划时复制为普通文本块）：

页面 ID：拟定稳定 ID。
地址：拟定 hash 或独立路径。
所属章节与位置：章节 ID，插在何页之后、何页之前；说明是否为独立翻页位置或页内标签。
标签：未完成。
教学目的：本页读完要理解或能够完成的具体任务。
全部内容：逐条写最终标题、导语、知识点、公式及符号、例题条件与结果、图示标签和含义、按钮与链接文字、注释与结论。
页内联系：说明各内容块为何这样组合，哪些是前提、推导、比较、例证或总结。
跨页联系：列出前后页 ID、前置概念所在页、后续使用本页概念的页、显式跳转入口。
交互：初始状态、用户动作、反馈、键盘行为、是否改变 URL 或页码；无交互则写无。
已完成内容：已存在的具体部分；新规划页写无。
未完成内容：尚需编写、绘制、核查或实现的具体内容，不写笼统的“完善”。
验收：能核对的知识目标、文字与图示完整性、导航和 1600 × 900 画布容纳情况。
源码位置：实现后对应的数据、组件和素材路径。

规划时优先复用已有模板；知识点太多或复杂图式超出画布时拆页。正文、图解和互动必须服务同一教学目的，避免只根据页面外观改写内容。任何新增事实、数值或外部案例应保留来源和核查范围，不把类比当成精确模型。
