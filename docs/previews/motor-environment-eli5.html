把风和海的力量，送到你身边

先变成电，再送过去，最后变成运动。

01 接住自然的力

风在吹，海浪在起伏，潮水在流。
发电机把这些运动变成电。

02 沿着电网送出去

风和海浪留在原地。
电能沿电网走，再分给许多地方。

03 在各处变成运动

电送到了。
电动机让身边的东西动起来。

自然的运动 → 发电机 → 电网 → 电动机 → 身边的运动
发电机：运动变成电电动机：电变成运动

风、浪、潮图示为常见机电发电方案；光伏直接产生电，核能经热能、汽轮机与发电机发电。电网像送能量的道路，需要变电与保护设施，传输有损耗；需要运动的用电器广泛使用电动机，并非所有用电器都有电机。

清洁电力驱动运动可避免运行中的燃烧尾气；制造、建设、能源开采与废物处理仍有环境影响，实际电网也可能混合化石能源。
