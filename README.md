# 电机与拖动 · 课堂讲义

用于替代课堂 PPT 的静态教学网站。初始框架包含课程封面，以及七章的章节导入和内容提纲，共 15 页。提纲为可调整的初稿，详细教学内容尚待补充。

## 启动

需要 Node.js 22.13+ 与 npm。

```sh
npm ci
npm run dev -- --port 5173
```

访问 http://127.0.0.1:5173 。运行不依赖外部字体、图片服务、数据库或账号。

```sh
npm run typecheck
npm run lint
npm run build
npm start
```

`npm start` 在 http://127.0.0.1:4173 预览构建后的静态文件。构建结果为 `dist/client/`，部署时只需上传该目录；`dist/server/` 是构建中间产物，不需要运行或部署。当前资源路径按域名根目录部署配置；若需要发布到 GitHub Pages 等子目录，请先配置对应的 basePath 并重新构建。不要用 file:// 双击打开构建文件，请使用 HTTP 静态服务器。

项目保留 Sites 生成的 React、TypeScript、Vite/Vinext 和 shadcn 组件结构。自定义构建入口使用同一构建与预渲染 API，让 Node 正常释放句柄，避免上游 CLI 在 Windows 上强制退出时的 libuv 崩溃。lint 检查课程源码及实际使用的组件，不包含其他未使用的脚手架组件。

## 课堂操作

| 操作              | 快捷键 / 方式        |
| ----------------- | -------------------- |
| 下一页            | →、↓、PageDown、空格 |
| 上一页            | ←、↑、PageUp         |
| 全屏演示 / 退出   | F / Esc              |
| 章节目录          | M                    |
| 第一页 / 最后一页 | Home / End           |
| 触屏翻页          | 左右滑动             |

目录按钮、侧边栏和页码两侧按钮同样可以导航。空格在按钮获得焦点时保留原生激活行为。每一页具有稳定的地址片段（例如 `/#transformers-outline`），支持刷新、直接访问和浏览器前进后退。全屏下将鼠标移至底部中央可显示工具栏，也可通过 Tab 聚焦。

所有页面以 **1600 × 900（16:9）** 固定画布布局并等比缩放。在 16:9 屏幕全屏时恰好填满屏幕，其他比例的屏幕居中留边。全屏需要浏览器允许 Fullscreen API；不支持时仍进入隐藏导航的课堂模式。手机保留幻灯片比例，建议横屏展示。

封面提供星系式知识图谱：点击七个章节星球即可进入对应章节；悬停或通过 Tab 聚焦时，高亮相关知识连线并显示本章问题。青绿、金色与紫色分别表示课程基础、直流电机和交流电机，箭头表示知识进阶关系。

## 文件与内容维护

```text
app/                       页面入口、元数据和全局样式
components/course-player.tsx  幻灯片模板、目录、快捷键和全屏播放器
components/chapter-galaxy.tsx 封面星系章节索引与知识关系
components/ui/             脚手架提供的可复用界面组件
content/course.ts          课程章节、学习目标、提纲和页面顺序
public/                    本地图片、图示等静态素材
scripts/build.mjs          静态构建入口
```

在 `content/course.ts` 中修改 `chapters` 可调整章节目标和提纲。向 `slides` 插入 `content` 页面即可添加知识点，页面会自动纳入导航、页码和章节列表。例如将下列对象放入 `slides` 中希望出现的位置（位于所属章节的提纲之后）：

```ts
{
  id: 'magnetic-circuits-basic-quantities',
  kind: 'content',
  chapterId: 'magnetic-circuits',
  title: '磁路中的基本物理量',
  lead: '建立磁路分析所需的物理量与单位。',
  points: [
    { title: '磁通 Φ', description: '描述穿过给定面的磁场通量。' },
    { title: '磁感应强度 B', description: '描述磁场的局部性质。' },
  ],
}
```

初始 `slides` 使用 `chapters.flatMap` 生成各章页面；建议为每章建立独立的内容文件，然后在 flatMap 中展开对应章节的页面数组，以保持章节顺序。每页 ID 必须唯一，`chapterId` 必须与现有章节对应。通用内容模板适合 2–4 个知识点，标题建议不超过 18 个汉字；复杂公式、动画和实验图可进一步扩展 `Slide` 类型和播放器中的模板分支。内容超过一页时应拆页，不使用页面内部滚动。
