## 电源变压器 ELI5 讲解页（新增）

- 交付物：`work/transformer-eli5.html`（单文件，无外部依赖，中文）。
- 素材来源：Pulse Electronics P666.E (07/19) 高频绕线变压器手册，Mouser 托管 PDF。
  注意：该系列是 **开关电源变压器**（Forward/Flyback，12 脚 SMT，95 W，11.4 mm 高，
  手册原理图标注 150–550 kHz），不是 50 Hz 工频变压器——页面开头专门纠正了这一点。
- 技术校对结论：PA0273NL 正激（Pri 307 µH，Lk ≤0.35 µH，DCR 65/27/240 mΩ，K1 20.2）；
  PA0751NL 反激（110 µH，2 µH，85/12/300 mΩ，K1 1364.8）；两者 Hi-Pot 1500 Vrms。
  Bpk = K1 × Ipk < 2700 G；铁损 ≈ 1.32e-13·f^1.63·ΔB^2.68。
- 页面结构：概念纠正 → 系统链路 → 剖面结构（7 处可点选高亮）→ 反激两态动画 →
  参数表 + K1 算例 → 代价/边界/误区 → 总结。所有 SVG 手绘内联，注意铁氧体是实心陶瓷，
  不能画成硅钢片叠片。
- 验证方式：本机 Chrome `--headless=new --screenshot` 分段截图（须经 PowerShell 调用，
  直接 Bash 调用 chrome 无输出）；窄屏最小布局宽度约 500 px。

## 隔离变压器 ELI5 讲解页（新增）

- 交付物：`outputs/isolation-transformer-eli5.html`（单文件，无外部依赖，中文）。
- 讲解主线：电气隔离 = 无导电路径（隔离路径不隔离能量）→ 为什么需要（TN 系统触电、
  地环路）→ 变压器靠磁通传能量（四步可点选）→ 1:1 悖论 → 边界（寄生电容频率上限、
  不限流、绝缘老化、浮空系统隐患、接法）→ 五个误区。
- 三个交互：① 触电图"再摸一根线"（证明隔离只断开对地回路）；② 四步高亮演示；
  ③ 泄漏电流 I=2πfCV 频率滑块（C=1 nF、V=230 V，50 Hz≈72 µA，1 MHz≈1.45 A）。
- 验证补充：Chrome headless 的 **虚拟时间不会推进 CSS transition**，导致 `opacity`
  过渡与按钮 `.on` 背景色在截图里始终停在初始值——验证交互状态时必须往 iframe 注入
  `*{transition:none!important}` 再截图，否则会误判为样式失效。
- 窄屏验证：`--window-size=390` 无效（Chrome 窗口有最小宽度），改用外层页面内嵌
  width:390 的 iframe 才能真实触发媒体查询。
